# Lua MediaPaper 1.1.0

Um projeto feito para minha amiga Lua! Feito com muito carinho...

- Interface shadcn/ui com Home, Definições e Mais.
- Wallpapers por link de foto, vídeo ou GIF e quatro fotografias incluídas para uso offline.
- **`/live`** ocupa a tela sem navbar, badges de prévia ou controles de edição.
- Alterações feitas em outra página ou dispositivo chegam ao `/live` em aproximadamente um segundo.
- Estado compartilhado persistente, com recuperação automática da conexão.
- Opção para manter a tela ligada usando Screen Wake Lock, com recuperação ao voltar à página.
- Conversor EPUB para PDF com imagens, capítulos e páginas numeradas.
- Aplicativo portátil Windows x64, bandeja do sistema e inicialização com o Windows.
- Modo servidor Python e Docker com volume persistente.

## Como usar

Baixe **Lua-MediaPaper.exe**, mantenha-o em uma pasta e execute. A Home abre em `http://127.0.0.1:8765/`; o wallpaper limpo fica em `http://127.0.0.1:8765/live`.

Na primeira execução, a inicialização com o Windows é ativada. Para desativar, abra Definições ou o menu do ícone na bandeja. Para encerrar completamente, use **Encerrar** nesse menu.

No `/live`, pressione **F** ou dê dois cliques para alternar a tela cheia nativa; **Esc** sai. Para manter a tela ligada em dispositivos acessando um servidor remoto, use **HTTPS** e um navegador com suporte a Screen Wake Lock. O sistema pode revogar esse recurso por economia de energia. O aplicativo não substitui o papel de parede nativo atrás dos ícones do Windows.

O arquivo **SHA256SUMS.txt** permite conferir a integridade do executável. Código-fonte e instruções de servidor estão no repositório.
